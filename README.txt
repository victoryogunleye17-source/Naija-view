NaijaView: installable version

Upload this whole folder to any https host (Vercel, Netlify, GitHub Pages).
Keep the files together: index.html, manifest.webmanifest, sw.js and the icon PNGs.

Test locally:  python -m http.server 8000   then open http://localhost:8000
Android/Chrome: browser menu > Install app (or the Install button inside NaijaView > Map view > App)
iPhone/Safari:  Share > Add to Home Screen
